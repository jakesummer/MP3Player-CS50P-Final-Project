# python-mp3-player
MP3 player made using Python and Tkinter

## Features
- Load up as many songs as you want
- Displays all metadata of songs (album cover, artist, song title, length)
- Skip forwards and backwards between songs
- Seek through songs
- Play/pause songs

## How to use
```
1. Download files
2. Install required packages from requirements.txt
3. Run mp3.py
```
